# Release 0.24.1

- Dark Mode verwendet einen dunkleren Navy-Hintergrund mit abgestimmten blauen Oberflaechen. Die bisherigen Standardpaletten werden aktualisiert; andere gespeicherte Farbvarianten bleiben erhalten.
- Der gemeinsame Profil-/XP-Button hat dieselbe feste Hoehe wie die benachbarten Toolbar-Icons: 42 px am Desktop, 40 px auf schmalen Bildschirmen. Kuerzel, Klasse und XP bleiben zweizeilig sichtbar.
- Verifiziert mit 103 Node-Tests sowie Profil- und Darstellungs-Browsertests in beiden Farbmodi, einschliesslich kleiner Bildschirme und grosser Schrift.
