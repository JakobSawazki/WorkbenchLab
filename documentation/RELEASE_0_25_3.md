# Release 0.25.3: dezente Profilinfo als eigener Layer

8. Oktober 2026

Das Info-Symbol neben dem Schülerkürzel ist jetzt ein kleiner, unaufdringlicher Button ohne metallischen Rahmen. Die vorhandenen Hinweise erscheinen in einem separaten nativen modalen Dialog über dem Profilfenster. Ein eigener Schließen-Button und Escape schließen nur den Hinweis. Danach kehrt der Fokus zum Info-Button zurück; Eingaben und Profilfenster bleiben erhalten.

Texte und Beispiele sind unverändert. CSS und App-Cache auf 0.25.3 gesetzt.

Prüfung: JavaScript-Syntax und Git-Diff fehlerfrei. Im Browser öffnen per Enter, schließen per Escape und Schließen-Button sowie Fokus-Rückkehr geprüft. Ungespeicherte Klasseneingabe bleibt erhalten. Mobile Ansicht bei 390 × 844 ohne horizontalen Überlauf; dunkles und helles Design geprüft.
